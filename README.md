# 个人简历网站

这是一个使用 React + TypeScript + Vite 构建的创意个人简历网站。

## 🎨 特性

- ✨ 动态粒子背景动画
- 🌙 深色主题设计
- 📱 响应式布局
- 🚀 流畅的动画效果
- 🎯 完整简历展示

## 🛠️ 技术栈

- React 18
- TypeScript
- Vite
- Framer Motion
- TailwindCSS
- Lucide Icons

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 🌐 部署

网站已部署到 GitHub Pages，并绑定到 diandiancookies.xyz 域名。

## 📝 修改简历内容

编辑 `src/data/resumeData.ts` 文件即可更新简历信息。
